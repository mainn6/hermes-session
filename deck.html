AI Agent Operator

Hermes Agent
알아보고, 실행하고, 활용하기

코드를 짜지 않는 사람이 AI 에이전트를 매일 업무에 쓰는 방법. 무엇인지, 제가 어떻게 쓰는지, 그리고 직접 설치하기.

01 Hermes Agent

폰에서 시키는 내 AI 비서

  • 내 컴퓨터에서 돌아가는 오픈소스 에이전트(NousResearch)
  • 텔레그램에 한 줄 보내면 파일·웹·메일·일정을 읽고 처리해서 답합니다
  • 자주 하는 일은 한 번 정해두면 정해진 시간에 알아서 돌아갑니다
  • 컴퓨터 앞에 없어도 됩니다. 저는 밖에서 폰으로 씁니다
02 구성

필요한 부품은 셋

컴퓨터Mac 또는 Windows. 에이전트가 여기서 돌아갑니다
텔레그램봇 하나. 폰에서 명령하고 결과를 받는 창
모델 키에이전트의 두뇌. 저는 Dgrid 한 키로 200개 모델을 골라 씁니다

그 위에 기억(Obsidian 볼트)과 스킬(메일·시트·이미지 같은 작업 묶음)을 얹습니다. 설치는 뒤에 실습으로.

03 제가 쓰는 방식

텔레그램 방이 업무 접수창

회사 텔레그램 그룹에 방을 여섯 개 두고, 방마다 스킬을 하나씩 묶었습니다. 사진이나 한 줄을 던지면 그 방의 스킬이 돌아갑니다.

업무보고방완료·진행·이슈·계획으로 정리 → 구글 Docs 상세 + 시트 요약 행
회의록방메모·녹취·화이트보드 사진 → 회의록 Docs + 시트
일정방“내일 3시 미팅” → 구글 캘린더 이벤트(+Meet)
명함방명함 사진 → 연락처 시트 행
지출방영수증 사진 → 경비 시트 행
General“주간 업무보고” → 위 시트 전체와 캘린더를 종합해 주간보고 Docs
04 사례 · 업무보고

세 줄 보내면 문서와 시트가 생긴다

  1. 업무보고방에 오늘 한 일 세 줄
  2. 에이전트가 완료 · 진행 · 이슈 · 계획으로 나눠 정리
  3. “이렇게 저장할게요, 맞나요?” → 확인
  4. Docs 상세 문서 생성, 시트에 요약과 링크 한 행

저장 전에 한 번 묻게 둔 이유: 잘못 들어간 행을 나중에 찾는 시간이 더 큽니다. 금요일엔 이 시트들을 모아 주간보고를 뽑습니다.

05 사례 · 반복 작업

매일 아침 9시, 시장 요약

  • 평일 09:00에 코스피·코스닥 전일 지수와 외국인·기관 수급을 읽어 한국어 5줄로 텔레그램에 보냅니다
  • 만든 방법은 대화 한 줄. “매일 9시에 이거 해서 보내줘. 반복 작업으로 등록해.”
  • 같은 방식으로 매일 10시 X 초안 세트, 소셜·깃허브 소재 수집이 돌아갑니다

코드를 짠 게 아니라 일을 말로 정해둔 것입니다. 안 맞으면 말로 고칩니다.

06 사례 · 이미지와 영상

포스터와 영상도 텔레그램에서

  • Higgsfield 스킬: “이 레퍼런스 톤으로 포스터 만들어줘” → GPT Image 2.5
  • “이 캐릭터가 돌아보는 3D 영상” → Seedance 2.5
  • 화면 안 글자는 AI에 맡기지 않고 따로 얹습니다. 시안은 480p, 채택분만 1080p

최근 실물: 투자자 디너 포스터, 소책자 표지 15장, 파트너십 발표 영상 19초. 전부 이 경로로.

07 구글 연동

Gmail · 캘린더 · 시트

  • 메일만 필요하면 Gmail 앱 비밀번호로 2분(himalaya 스킬)
  • 캘린더·시트·문서까지면 Google Cloud OAuth 한 번(google-workspace 스킬, 5분)
  • 읽기·요약·초안은 에이전트가, 발송과 수정은 확인 후
“오늘 안 읽은 메일 요약해줘”
“이 메일에 답장 초안 써줘. 보내기 전에 보여줘”
“이번 주 일정 겹치는 거 있어?”
08 기억

Obsidian 볼트 = 에이전트의 기억

  • 에이전트 자체 메모리는 2,200자. 긴 기록은 볼트(markdown 폴더)에 씁니다
  • 정체성 파일에 한 줄: “프로젝트 질문은 답하기 전에 볼트를 먼저 검색한다”
  • 밖에서 “그 링크 어디 저장했지?” 하면 파일명을 찍어 답합니다. 저도 같은 파일을 봅니다

진실은 채팅이 아니라 볼트에 있습니다. 저장 안 된 결정은 없는 결정.

09 원칙

회사에서 써도 되는 조건 셋

  1. 위험한 일은 실행 전에 묻는다. 메일 발송 · 결제 · 삭제
  2. 진실은 볼트에. 채팅은 흘러간다
  3. 키는 파일에만. 채팅 · 스크린샷 · 문서에 안 남긴다
