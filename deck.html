Hermes가 뭐냐

텔레그램 한 줄에 일하는 비서

  • 내 컴퓨터에서 돌아가고, 폰 텔레그램에서 명령합니다
  • 파일을 읽고 쓰고, 웹을 보고, 명령을 실행하고, 정해진 시간에 반복합니다

STEP 01

가장 쉬운 길은 데스크톱 설치 파일. 막히면 터미널 한 줄.

hermes --version
STEP 02

  1. dgrid.ai/api-keys → Sign in → 지갑 연결

  4. 키는 한 번만 보입니다 → 메모장

안전 규칙

강사 화면에 상시

  • API 키는 읽기 + 거래만. 출금 권한 절대 OFF. IP 화이트리스트
  • 모의 계정 또는 잔고 0 계정만. 실돈 계정 연결은 강사가 막습니다
  • 1회 한도는 숫자로. 초과 주문은 거절 후 사람에게
  • 서킷 브레이커: 가스 부족 → 정지 · 자본 하한 → 정지 · 연속 실패 20회 → halt
  • 키·토큰이 화면에 비치지 않게. 입력은 설정 프롬프트로만
블록 5

먼 지정가 → 취소

  1. “규칙대로 지금 판단해”
  2. 에이전트가 규칙 카드 확인 → 현재가 대비 30% 아래 BUY 지정가 0.0001 BTC (체결 불가)
  3. 주문 ID · 상태 4(대기) 보고
  4. 10초 대기 (거래 호출은 키당 10초 1회)
  5. “취소해” → 주문 목록에서 사라진 것 확인

조건이 안 맞으면 no-trade가 정답입니다. 그것도 완료.
