Hermes Agent
설치와 연결

위에서부터 하나씩. 각 단계의 복사 버튼을 눌러 터미널에 붙입니다. 키와 토큰은 채팅방에 올리지 않습니다. 질문은 디스코드에서. 강사 화면용 실습 덱: practice.html

STEP 00

준비물 확인

  • 노트북: Mac(Apple Silicon) 또는 Windows 11. 인텔 맥은 미지원.
  • 텔레그램: 폰과 노트북 둘 다 로그인.
  • 지갑 앱(MetaMask 등) 1개. Dgrid 로그인용. 없으면 강사에게 세션용 키를 받습니다.
  • 오늘 만드는 값 3개는 메모장에만 적습니다: Dgrid 키 · 봇 토큰 · 내 텔레그램 ID. 채팅방에 올리지 않습니다.
STEP 01

Hermes 설치

가장 쉬운 길은 데스크톱 설치 파일입니다. QR을 열어 Download를 누르고 실행하면 명령줄과 앱이 함께 설치됩니다.

설치 파일이 막히면 아래 한 줄을 터미널(Mac: Terminal / Windows: PowerShell)에 붙입니다.

Mac 터미널
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
Windows PowerShell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
설치 확인 (터미널을 새로 열고)
hermes --version
STEP 02

Dgrid에서 모델 키 만들기

  1. QR → dgrid.ai/arena?code=5GG6FQ 로 가입. 오른쪽 위 Sign in → 지갑 연결.
  2. dgrid.ai/api-keys → Dashboard → Keys → Create New Key.
  3. 이름 hermes-session, Credit limit 5, Create.
  4. 키는 한 번만 보입니다. Copy → 메모장.

오늘은 무료 라우터 모델 dgridai/free를 씁니다. 크레딧 충전 없이 됩니다. 나중에 특정 모델을 쓰려면 Billing → Deposit(USDT·USDC·BNB) 또는 Redeem Code.

STEP 07

집에 가서 붙이는 것: 업무 패턴 3개

오늘 따라 하지 않아도 됩니다. 에이전트를 업무에 붙이는 흔한 구성 세 가지입니다.

① 텔레그램 방 = 업무 접수창

텔레그램 그룹에 토픽(방)을 만들고, 방마다 스킬을 하나씩 묶는 구성입니다. 사진이나 한 줄을 던지면 그 방의 스킬이 돌아갑니다. 예를 들면 이런 식입니다.

업무보고방완료·진행·이슈·계획으로 정리 → 구글 Docs 상세 + 시트 요약 행
회의록방메모·녹취·화이트보드 사진 → 회의록 Docs + 시트 요약
일정방"내일 3시 미팅" → 구글 캘린더 이벤트(+Meet 링크)
명함방명함 사진 → 연락처 시트 행
지출방영수증 사진 → 경비 시트 행
General"주간 업무보고" → 위 시트 전체 + 캘린더 종합해 주간보고 Docs

저장 직전에 항상 "이렇게 저장할게요, 맞나요?"를 한 번 묻게 해 둡니다. 사람이 마지막 확인.

② 반복 작업(크론)

정해진 시간에 웹을 읽고 요약을 텔레그램으로 보내는 반복 작업은 대화 한 줄로 등록됩니다. 예시:

텔레그램에 그대로 보내기
매일 평일 아침 9시에 코스피·코스닥 전일 지수와 외국인·기관 매매동향을 네이버 금융에서 읽어 한국어 5줄로 요약해서 이 방으로 보내줘. 반복 작업으로 등록해.

③ Obsidian(옵시디언) 연결 3단계

에이전트 자체 메모리는 2,200자가 한계입니다. 긴 기록은 Obsidian 볼트(그냥 markdown 폴더)에 쓰게 합니다. 사람도 같은 파일을 봅니다.

  1. Obsidian 설치 → 볼트 폴더 하나 만들기. 처음엔 전용 폴더(예: vault/hermes)만 열어 줍니다.
  2. 기본 스킬 obsidian이 이미 들어 있습니다. 확인:
스킬 확인
hermes skills list | grep -i obsidian
  1. 에이전트 정체성 파일 ~/.hermes/SOUL.md에 볼트 경로와 저장 규칙을 적습니다. 아래를 붙이고 경로만 바꾸세요.
SOUL.md 템플릿 (경로 수정)
너는 [내 이름]의 AI 에이전트다. 파트너이자 집행자.

## 톤
- 짧고 직설적. 결론부터. 한국어.
- 수치가 있으면 수치로 말한다.

## 지식 저장소 (Obsidian)
- Vault 경로: /Users/[me]/Obsidian/vault
- 대화에서 나온 아이디어·링크·결정은 vault에 markdown으로 저장하고 [[wikilink]]로 연결한다.
- 프로젝트 질문을 받으면 답하기 전에 vault를 먼저 검색한다(search_files → read_file).
- 저장하면 파일 경로와 한 줄 요약만 답한다.

## 안전
- 메일 발송, 결제, 삭제, 실거래, 대량 발행은 실행 전에 반드시 나에게 확인한다.
- 키·토큰·비밀번호는 어디에도 적지 않는다.

그 다음 텔레그램에 링크 하나 보내며 "볼트에 저장해"라고 하면 파일 경로가 답으로 옵니다. Obsidian에서 바로 보입니다.

④ 이미지·영상은 Higgsfield 스킬로

"이 레퍼런스 톤으로 포스터 만들어줘" 한 줄이면 GPT Image 2.5로 이미지가, "이 캐릭터가 돌아보는 3D 영상" 하면 Seedance 2.5로 클립이 나옵니다. 텔레그램에서 시키고 결과 파일을 받는 흐름은 다른 스킬과 같습니다.

크레딧이 드는 작업이라 시안은 저해상도(480p)로 뽑고 채택분만 1080p로 다시 만듭니다.

⑤ 원칙 세 개

위험한 일은 실행 전에 묻는다. 메일 발송·결제·실거래·삭제.
진실은 채팅이 아니라 볼트에 있다. 저장 안 된 결정은 없는 결정.
키는 파일에만. 채팅·스크린샷·문서에 안 남긴다.
STEP 08

구글 연동 (Gmail · 캘린더 · 시트)

집에서 하는 단계입니다. 둘 중 하나를 고릅니다.

A. 메일만 — Gmail 앱 비밀번호 (약 2분)

  1. 구글 계정 → 보안 → 2단계 인증 켜기 → 앱 비밀번호 생성(16자)
  2. 텔레그램에서 에이전트에게: “himalaya 스킬로 내 Gmail 연결해줘” → 주소와 앱 비밀번호를 물어옵니다
  3. 확인: “안 읽은 메일 5개 요약해줘”

B. 메일 + 캘린더 + 시트 + 문서 — Google Cloud OAuth (약 5분, 한 번)

  1. 텔레그램에서: “google-workspace 스킬 설정 시작해줘”
  2. 에이전트가 순서를 안내합니다: Google Cloud 프로젝트 만들기 → API 6개 켜기(Gmail·Calendar·Drive·Sheets·Docs·People) → OAuth 클라이언트(Desktop app) 만들기 → JSON 다운로드 → 파일 경로 알려주기 → 브라우저 로그인 → 코드 붙이기
  3. 확인: “이번 주 일정 겹치는 거 있어?”
설정 상태 확인 (터미널)
python3 ~/.hermes/skills/productivity/google-workspace/scripts/setup.py --check

읽기·요약·초안은 에이전트가 하고, 발송과 수정은 실행 전에 확인을 받게 둡니다. JSON 파일과 비밀번호는 채팅에 올리지 않습니다.

모델 키는 Dgrid(api.dgrid.ai), 에이전트는 Hermes Agent(NousResearch). 세션이 끝나면 오늘 만든 키를 삭제해도 됩니다.
