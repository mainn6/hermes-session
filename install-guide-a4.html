내 폰에서 명령하는 AI 에이전트 — 세팅 6단계

Hermes Agent × Dgrid × Telegram
키·토큰은 메모장에만. 채팅방에 올리지 않습니다.
STEP 01

Hermes 설치

QR → Download 실행. 또는 터미널:
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
확인: hermes --version

STEP 02

Dgrid 키

QR로 가입(지갑 로그인) → dgrid.ai/api-keys → Keys → Create New Key
이름 hermes-session · 한도 5 · 한 번만 보임 → 메모장

STEP 03

모델 연결

hermes model → Custom endpoint
URL https://api.dgrid.ai/v1 · 키 · 모델 dgridai/free
확인: hermes -z "한 줄로 인사해줘"

STEP 04

텔레그램 봇

@BotFather /newbot → 토큰 · @userinfobot → 내 ID
hermes gateway setup → Telegram → 토큰·ID
hermes gateway 켜고 폰에서 “안녕”

STEP 05

완료 체크

curl -fsSL https://mainn6.github.io/hermes-session/check.sh -o check.sh && bash check.sh
5개 PASS → 완료 조건 1 통과

STEP 00

참가자 페이지
