[세션 전날 또는 시작 10분 전]

안녕하세요. 오늘은 코드를 짜는 대신 내 폰 텔레그램에서 명령하는 AI 에이전트(Hermes)를 직접 세팅합니다. 3시간 끝에 "텔레그램 한 줄 → 에이전트가 시장을 읽고 규칙대로 모의 주문 → 취소 → 노트에 기록"까지 한 바퀴 돕니다. 실돈 거래는 하지 않습니다.

준비물
1. 노트북: Mac(Apple Silicon, M1 이후) 또는 Windows 11. 인텔 맥은 지원되지 않습니다.
2. 텔레그램: 폰과 노트북 둘 다 로그인.
3. 지갑 앱(MetaMask 등) 1개. Dgrid 모델 키 발급 로그인에 쓰입니다. 없으면 현장에서 세션용 키를 드립니다.
4. (선택) Obsidian 설치.

미리 해두면 좋은 것
- 참가자 페이지 열어 STEP 01(설치)만 끝내 두기: https://mainn6.github.io/hermes-session/
- 설치 중 막히면 그 화면을 사진으로 찍어 두세요. 현장에서 같이 봅니다.

중요
- API 키와 봇 토큰은 채팅방에 올리지 않습니다.
- 거래소 키는 오늘 발급하지 않습니다. 강사가 시연용 계정으로 보여줍니다.

[0:25 — 채팅방]
참가자 페이지 STEP 01을 여세요. 설치가 끝난 분은 터미널에 hermes --version 을 쳐서 버전이 나오면 손 들어 주세요.

[0:40 — 채팅방]
STEP 02. QR로 dgrid.ai/api-keys 에 들어가 지갑으로 로그인하고 키를 하나 만듭니다. 키 이름은 hermes-session, 크레딧 한도는 5로 두세요. 키는 한 번만 보입니다. 메모장에 붙여 두세요. 지갑이 없는 분은 손 들어 주세요. 세션용 키를 드립니다.

[0:50 — 채팅방]
STEP 03. 터미널에 hermes model 을 치고 Custom endpoint 를 고른 뒤 세 줄을 넣습니다. 주소 https://api.dgrid.ai/v1 , 키, 모델 dgridai/free . 끝나면 hermes -z "한 줄로 인사해줘" 를 쳐서 답이 오는지 봅니다.

[1:05 — 채팅방]
STEP 04. 폰 텔레그램에서 @BotFather → /newbot 으로 봇을 만들고 토큰을 받습니다. @userinfobot 으로 내 ID 숫자를 받습니다. 터미널에 hermes gateway setup → Telegram → 토큰과 ID를 넣고, hermes gateway 로 켭니다. 폰에서 봇에게 "안녕"을 보내세요.

[1:20 — 채팅방]
STEP 05. 터미널에서 bash check.sh 를 돌려 전부 PASS인지 확인합니다. FAIL이 있으면 그 줄을 사진으로 보내 주세요.

[1:40 — 채팅방]
규칙 카드를 종이에 씁니다. 종목 1개 / 진입 조건 1개 / 손절 % / 익절 % / 1회 주문 한도 / 거래 금지 조건 / 하루 최대 손실. 다 쓰면 사진을 찍어 두세요.
