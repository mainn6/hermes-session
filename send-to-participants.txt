[세션 전날 또는 시작 10분 전]

안녕하세요. 오늘 세션은 세 부분입니다. ① Hermes Agent가 무엇이고 제가 어떻게 쓰는지 설명 ② 디스코드 입장 ③ 직접 설치하고 텔레그램에 연결하는 실습.

준비물
1. 노트북: Mac(Apple Silicon, M1 이후) 또는 Windows 11. 인텔 맥은 지원되지 않습니다.
2. 텔레그램: 폰과 노트북 둘 다 로그인.
3. 지갑 앱(MetaMask 등) 1개. 모델 키 발급 로그인에 쓰입니다. 없으면 현장에서 세션용 키를 드립니다.

설치 가이드와 자료는 디스코드에 있습니다. 세션 중 QR로 안내합니다.

디스코드 입장: https://discord.gg/TBuVE4mnhr

[디스코드 #hermes-session 에 고정할 글]
참가자 페이지 (설치·연결 순서, 복사 버튼): https://mainn6.github.io/hermes-session/
설치 가이드 A4 PDF: https://mainn6.github.io/hermes-session/install-guide-a4.pdf
완료 체크 스크립트: curl -fsSL https://mainn6.github.io/hermes-session/check.sh -o check.sh && bash check.sh
키·토큰·비밀번호는 여기 올리지 마세요. 막히는 화면은 스크린샷으로.

[실습 시작]
참가자 페이지 STEP 01부터. 설치가 끝난 분은 터미널에 hermes --version 을 쳐서 버전이 나오면 손 들어 주세요.

[실습 +15분]
STEP 02~03. Dgrid 키를 만들고 hermes model 로 연결합니다. 지갑 없는 분은 손 들어 주세요.

[실습 +30분]
STEP 04. 텔레그램 봇을 만들고 hermes gateway 로 켠 뒤 폰에서 "안녕"을 보내세요.

[실습 +45분]
STEP 05. bash check.sh 로 전부 PASS인지 확인합니다. FAIL 줄만 스크린샷으로.

[거래소 블록 시작]
규칙 카드를 종이에 씁니다. 종목 1개 / 진입 조건 1개 / 손절 % / 익절 % / 1회 주문 한도 / 거래 금지 조건 / 하루 최대 손실.

[마무리]
옆 사람 봇에 "잔고 알려줘"를 보내 답이 오면 완료입니다. 집에 가서 실돈 계정에 연결하지 않습니다.
